#  OS Flashing

在编译内核并生成vmlinuz镜像时就将内核和rootfs打包在一起，更新vmlinuz 即是将OS更新，如果需要修改rootfs ，请使用buildroot构建新的rootfs，生成rootfs压缩文件的路径填写在linux 配置文件中，可以通过指令make menuconfig 直接添加，具体添加方式可以通过chatgpt查询。 

```shell

dfu /dev/fs/ext3@wd0b/vmlinuz
```

# CAN-FD

``` shell

	#设置canfd命令
	ip link set down can0
	ip link set up can0 type can bitrate 1000000 dbitrate 5000000 fd on
	ip link set up can0
	
	ip link set down can1
	ip link set up can1 type can bitrate 1000000 dbitrate 5000000 fd on
	ip link set up can1
	#设置can命令
	ip link set down can0
	ip link set up can0 type can bitrate 500000
	#性能测试
	time cangen can0 -f -b -g 1 -i 100 -L 64 -n 1000
	# 变速测试
	cangen can0 -f -b -g 1000 -i 100 -L 64 -n 1
	# 显示一下can信息
	ip -details link show can0

```

# JTAG Program Flash



1、确保开发板断电，ejtag已和电脑连接
2、打开ejtag软件即：loongson-debugger  双击la_dbg_tool_usb.exe   会弹出终端
3、在终端中输入source configs/config.ls2k2000  点击回车
4、输入set 点击回车
5、给开发板上电    会返回寄存器状态，如果长时间没反应说明没有和芯片通讯上，此时如过确认板卡状态没有问题，请从1重新操作
 6、输入call program_cachelock image.bin    点击回车 此指令为烧录指令，第三个参数为要烧录的文件
