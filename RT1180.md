# Boot ROM 支持以下主要启动设备

- 通过 FlexSPI 接口连接的串行 NOR Flash
- 通过 FlexSPI 接口连接的串行 NAND Flash
- 通过 SEMC 接口连接的 SLC RAW NAND Flash
- 通过 uSDHC 接口连接的 SD 卡或嵌入式多媒体卡（eMMC）
# 控制启动接口

- ROM API
- Fuse
- BOOT pin
